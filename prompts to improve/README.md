# Prompts to improve

These are proposals for a future implementation session. Creating these files does not implement, approve, activate or certify any feature described inside them.

Use `01-RELIABILITY-AND-COMPLETION.md` first. It closes the evidence and quality gaps before expanding the product. Then use `02-LEARNING-EXPERIENCE.md` and `03-PAID-PRODUCT-READINESS.md` in bounded phases.

The intended outcome is a study resource comprehensive and reliable enough to earn students' trust and justify payment. Pearson's current specification remains the authority for exam scope. Do not market the product as replacing official requirements, guaranteeing grades or diagnosing a learner's ability.

Keep the existing Japanese-inspired crimson library, readable light notes, dark quiz room, rectangular controls, one-question exam flow and pseudonym-based entry unless the owner asks to change them. Do not add neon colours, pill-shaped controls or decorative effects that interfere with reading.

Current limitations must be checked against the latest coverage ledger and checkpoint, not inferred from these proposals. The proposed features below are deliberately not implemented by the AI integration task.
